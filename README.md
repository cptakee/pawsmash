# Paw Smash website

A responsive, static landing page for Paw Smash, a cat-themed physics smash puzzle game. Built with HTML, CSS and vanilla JavaScript; free to host with GitHub Pages.

## Publish on GitHub Pages

1. Create a public repository named `pawsmash` in your GitHub account.
2. Upload **all files and folders** from this project. Keep `index.html` in the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub to publish the site. Your address will look like `https://YOUR-USERNAME.github.io/pawsmash/`.

## Before launch: customize these items

- Replace `assets/hero-cat.svg` and `assets/character-cat.svg` with your approved Paw Smash character artwork. Keep the same filenames, or update the image paths in `index.html`.
- Replace the sample gallery panels in `index.html` with real gameplay screenshots.
- The homepage has no store buttons. The final orange section is contact-only and links to akegamesinc@gmail.com.
- Company/contact details are set to AKEGAMES INC, Istanbul, Turkey and akegamesinc@gmail.com.
- Complete every bracketed field in `privacy.html` and `terms.html`; these are starter templates, not legal advice.
- Check the Privacy Policy against the actual SDKs and data collected by your released game. Add the exact analytics, attribution and ad providers and their privacy links.
- Have both legal pages reviewed for the countries where you distribute the game before launch.
- Update page title, description and social preview text in the `<head>` of `index.html`.

No build tools, paid hosting, or backend are required. Google Fonts is an optional externally loaded font; the page has local fallback fonts.
